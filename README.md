# Legacy Rents: new homepage (design preview)

A static build of the new Legacy Rents homepage, from Daniela's branding board and homepage mockup. It uses the layout style of the Fairgrove landing page.

**Preview only.** legacyhomesrent.com is untouched. The page is `noindex, nofollow`.

- `index.html`: the page
- `assets/css/lr.css`, `assets/js/lr.js`: styles and interactions, no build step
- `assets/img/`: compressed WebP photos and the SVG favicon
- `COMPARISON.md`: what happens to each of the 11 sections of the live homepage

Brand: navy `#0F2D4A`, teal `#34C6BE`, light teal `#BEE5DD`, light gray `#F5F7F9`. Playfair Display for headings, Inter for body text.

Run locally: `python -m http.server 8098`, then open http://127.0.0.1:8098/
